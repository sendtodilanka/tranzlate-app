"මේක හරවන්න" කියලා අහනවා. කුමන ක්‍රමය (auto / offline / online / AI), එකක් fail වුණොත් ඊළඟ එක, පරණ උත්තර මතක තියාගැනීම — ඔක්කොම මේක. තිර විස්තර දන්නේ නෑ.

👤 දායකත්ව මොළය

"මේ user ට මේක පුළුවන්ද? සීමාව මොකක්ද?" — Free / Plus / Premium ගැන දන්නේ මේක විතරයි. තිර 8ක check කරන එක නවතිනවා.

📊 සීමා මොළය

දවසේ භාවිතය එක තැනකින් count කරනවා, දවස මාරු වුණාම reset කරනවා. සාර්ථක වුණාම විතරයි +1 (දැන් වගේ දෙපාරක් නෙවෙයි).

📣 දැන්වීම් මොළය

දැන්වීමක් පෙන්නන්නේ කවදද කියලා එක තැනකින් තීරණය — පරිවර්තනයක් ඉවර වුණාම විතරයි, Back එබුවම නෙවෙයි.

උදාහරණයක් — text එකක් හරවනකොට
  1. Text තිරය: පරිවර්තන මොළයට කියනවා "මේ 'Good morning' එක French වලට හරවන්න."
  2. පරිවර්තන මොළය: දායකත්ව මොළයෙන් අහනවා "මේ user ට පුළුවන්ද? සීමාව ඉවරද?"
  3. පුළුවන් නම් → හරි ක්‍රමයෙන් හරවනවා (පරණ උත්තරයක් තියෙනවනම් ඒක දෙනවා, කාලය ඉතුරු).
  4. සාර්ථක නම් → සීමා මොළය +1, උත්තර දත්ත වලට save.
  5. දැන්වීම් මොළය: "දැන් දැන්වීමක් ඕනද?" බලනවා.
