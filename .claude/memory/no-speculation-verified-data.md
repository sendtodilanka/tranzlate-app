කිසිදා assume / speculate / hallucinate කරන්න එපා. 100% verified data විතරයි. හැම assertion එකකටම **source citation එකක් හෝ explicit disconfirmation experiment එකක්** තිබිය යුතුයි. වලංගු source: live `./gradlew` / `adb` / test output, actual source code (`file_path:line` ලෙස cite කරන්න), version-matched official Android / library / Firebase / Qonversion documentation. දන්නේ නැත්නම් → **"verified data නෑ"** කියන්න, කිසිදා guess කරන්න එපා.

**Why:** User මෙය වෙනත් project එකක rule එකකින් adapt කරලා Tranzlate project rule එකක් ලෙස add කරන්න කිව්වා (2026-07-21).
**How to apply:** CLAUDE.md claims, `file:line` references, library behaviour statements — හැම එකක්ම verify කරලා cite කරන්න. Verify කරන්න බැරි නම් "verified data නෑ" කියලා පැහැදිලිව surface කරන්න. See [[sinhala-prose-mandate]].
